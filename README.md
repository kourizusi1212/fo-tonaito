# BUILD BATTLE ONLINE
フォートナイト風の3Dオンライン対戦（Node.js + WebSocket + three.js）

## ゲームルール
- ロビー: クイックマッチ / ルーム作成（4文字コードで友達を招待）。ホストが開始（最大12人）
- 初期装備は**ピッケルのみ**（木材50）。銃・弾・回復・シールドはマップ上で拾う
- ピッケルで木を叩くと木材(+15)。壁10 / 床10 / 階段20 の木材で建築
- 銃スロットは3つ。満杯のときは E で足元の銃と交換。同じ銃を拾うと弾が増える
- 回復: Z包帯(+15,最大75) / Xメディキット(HP100) / C小シールド(+25,最大50) / V大シールド(+50,最大100)
- 復活なし。最後の1人が勝者。脱落後は観戦、6秒後に全員ロビーへ

## ローカル
```
npm install && npm start   # http://localhost:3000 を複数タブで開く
```

## GitHub → Render
1. このフォルダをGitHubへpush
2. Render → New + → Blueprint → リポジトリ選択（render.yaml自動検出）
3. 発行されたURLを共有

※無料プランは15分無通信でスリープ（復帰に約1分）
